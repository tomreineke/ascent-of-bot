# Conventions

This folder documents **rules every developer must follow** when writing code: naming, style, patterns, library usage, and structural constraints.

These are **living documents** — enforced during code review. When a reviewer catches a repeated violation, it often signals the convention is unclear and needs a clarification update here.

## Topics

- **Kotlin Style & Naming** — Code style, naming conventions, idiomatic patterns
- **Skiatree Nodes & Layout** — How to build UI components, layout constraints
- **Action System** — How to define and implement actions, emit animation events
- **Resource Management** — AutoCloseable patterns, native pointer cleanup
- **Error Handling** — What to validate at system boundaries vs. trust internally
- **Testing** — Test structure, unit vs. integration, mocking patterns
- **Networking** — Client-server message protocol, data serialization
